# Darkwood dressed walk script (feel pass)

Use with `graybox/index.html` via `npx serve` (see README). Reset the on-screen timer before you start if you want a clean elapsed reading.

1. Start at shack (S) — notice cabin props
2. Walk ring road clockwise (or full circle) — tents on shoulders, denser woods W/S
3. Visit SW legendary — dragon + beasts cluster
4. Visit NE spirit — ruins, ghost, scorched/bare trees
5. Cross both bridges onto center platform — bandit hideout props
6. Walk north road to fire-curse wall — glowing north blockage
7. Return to shack

Judge: Does the biome *feel* like Darkwood? Are regions readable without combat? Is end-to-end pace still ~45–60s? Any prop scale/overlap that breaks the walk?
